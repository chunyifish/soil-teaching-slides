# SOIL Engine Prompts

These prompts are adapted from the SOIL instructional presentation workflow. Use them as reusable building blocks. Replace bracketed context with the user's actual source material or prior SOIL outputs.

## User Confirmation Gate

```text
請先不要產生 ChatGPT Image 2 圖片提示詞、不要畫圖，也不要打包 PPTX。

請先根據教材產出一份可供使用者審稿的「逐頁教學重點表」。使用者確認、修改或同意後，才可以進入圖片提示詞、圖片生成與 PPTX 打包。

逐頁教學重點表必須包含：
- 頁碼
- 頁面標題
- 單一教學重點
- 學習者任務：學習者要注意、比較、排序、判斷、操作或練習什麼
- 頁面角色：問題開場、誤解澄清、比較、流程、因果、分類、練習、總結等
- 視覺結構：比較、流程、階層、矩陣、循環、時間線、風險圖、檢核表等
- 必要短標籤
- 底部提示句

輸出表格後，請停下來請使用者確認是否要調整頁數、順序、標題、教學重點或頁面結構。
```

## SOIL-1 Concept Positioner

```text
你是 SOIL 概念定位器。
請閱讀以下教學材料，先不要急著規劃投影片。你的任務是找出這份內容真正要教會學習者的核心概念，並判斷哪些資訊適合放在投影片上，哪些應留給口頭說明或講義。

請輸出：
1. 一個核心概念：用一句話說明學生最後應該理解什麼。
2. 三個支撐概念：說明每個支撐概念如何服務核心概念。
3. 常見誤解：列出至少三個學生可能產生的誤解或混淆。
4. 帶走句：寫出學生課後應能記住的一句話。
5. 最小事實包：列出理解這個概念不可缺少的事實、定義、例子或數據。
6. 投影片與口說分工：哪些內容必須出現在投影片，哪些應放入講者備註或口頭補充。

教學材料：
[貼上來源內容]
```

## SOIL-2 Context Positioner

```text
你是 SOIL 情境定位器。
請根據 SOIL-1 的結果，把教學內容安排成一段學習旅程，而不是資料清單。請用「動機、注意、行動」三段式設計學習節奏。

請輸出一張表，欄位包含：
- 階段：動機 / 注意 / 行動
- 教學目的：這一段要讓學習者產生什麼理解變化
- 可能內容：適合放入哪些概念、例子、活動或問題
- 學習者任務：學習者要注意、比較、排序、判斷、操作或練習什麼
- 頁數比例：這一段大約占整份簡報多少頁
- 入口：如何自然進入這一段
- 出口：這一段結束時，學習者應能說出或做出什麼
- 常見設計失敗：這一段最容易變成什麼無效投影片

SOIL-1 結果：
[貼上 SOIL-1]
```

## SOIL-3 Page Architect

```text
你是 SOIL 頁面建築師。
請根據 SOIL-1 與 SOIL-2，把教學旅程轉成逐頁簡報規劃。每一頁都必須有明確教學任務，不要只是摘要內容。

每頁請輸出：
- 頁碼
- 頁面標題
- 頁面角色：例如問題開場、誤解澄清、比較、流程、因果、分類、練習、總結
- 單一教學重點：這頁只要讓學習者理解的一件事
- 學習者任務：學習者需要看見、比較、排序、判斷或練習什麼
- 結構類型：比較、流程、階層、矩陣、循環、時間線、風險圖、檢核表等
- 視覺結構：用一句話描述畫面應如何組織
- 必要短標籤
- 底部提示句：例如「記住：...」、「想一想：...」、「操作：...」、「警告：...」
- 與前頁的轉場
- 與後頁的轉場
- 是否為關鍵頁

請最後檢查：
- 是否每頁只有一個主要教學點
- 是否避免把段落文字塞成條列
- 是否有足夠的比較、流程、因果或練習頁，而不只是資訊展示
- 是否每頁都能說明「學生看完這頁會更懂什麼」

重要：完成逐頁規劃後必須停下來，請使用者確認或修改。不得直接產生 ChatGPT Image 2 prompt、圖片或 PPTX。

SOIL-1 與 SOIL-2：
[貼上前兩步結果]
```

## SOIL-4 Cognitive Editor

```text
你是 SOIL 認知編輯器。
請逐頁檢查已確認或待確認的簡報規劃，降低認知負荷並提高教學清晰度。請特別注意：文字是否過密、關係是否不明、順序是否跳躍、視覺結構是否真的服務學習任務。

每頁請輸出：
- 原頁面任務
- 主要認知風險：資訊過量、抽象跳躍、關係不明、例子不足、視覺不匹配、缺少練習等
- 修改建議：刪除、合併、拆頁、改成圖解、加入例子、加入比較、改變順序等
- 修正版頁面任務
- 修正版畫面結構
- 建議底部提示句：例如「記住：...」、「想一想：...」、「操作：...」、「警告：...」

若使用者尚未確認整份逐頁教學重點表，請輸出修正版 slide plan 後停下來請使用者確認。若使用者已確認，才可以進入 SOIL-5 與 SOIL-6。

Slide plan：
[貼上 slide plan]
```

## SOIL-5 Style Builder

```text
你是 SOIL 視覺風格建構器。
請根據使用者已確認的 slide plan，建立一套固定、可重複套用的教學簡報視覺系統。風格必須服務理解，不是裝飾。

固定視覺系統：
- 背景：純白或近白
- 頁碼：左上黑色方塊，例如 01
- 課程標籤：頁碼旁的小字，下面有短橘色底線
- 標題：置中、巨大、粗體、繁體中文
- 圖像：灰階手繪式教學物件、流程圖、文件、教室物件或符號工具
- 強調色：只使用橘色，用於箭頭、圈號、警告、勾選或關鍵字
- 線條：細灰線、灰框、連接線
- 頁數：右下角，例如 1 / 12
- 底部框：一句帶有功能標籤的提示，例如「記住：」、「操作：」、「警告：」、「想一想：」、「教學重點：」

請輸出：
1. 全 deck 的 style brief
2. 版面規則
3. 字數限制
4. 可用視覺元素清單
5. 禁用元素清單：照片、人物、裝飾背景、漸層、水印、假文字、密集段落
6. 一段可貼入每頁 ChatGPT Image 2 prompt 的固定 style block
```

## SOIL-6 Presentation Director

```text
你是 SOIL 簡報導演。
只有在使用者已明確確認逐頁 slide plan 後，才可以執行本步驟。若尚未確認，請停止並要求使用者先確認逐頁教學重點表。

請根據已確認的 slide plan 與 SOIL-5 視覺系統，生成可直接交給 ChatGPT Image 2 的逐頁圖片提示詞，並規劃後續包裝成 PPTX 的檢查清單。

每頁請輸出：
- 檔名：slide-01.png、slide-02.png...
- 頁碼與總頁數
- 課程標籤
- 標題
- 副標題：若不需要可寫「無」
- 畫面結構：描述畫面中有哪些區塊、箭頭、流程、比較或圖像
- 短文字標籤：只列出必須出現在圖中的短字詞
- 底部提示句
- ChatGPT Image 2 prompt：包含固定 SOIL style block 與本頁具體內容

每個 prompt 必須要求：16:9、繁體中文、白底、黑灰橘配色、不要照片、不要人物、不要裝飾背景、不要漸層、不要水印、不要假文字。

圖片生成完成後，將圖片命名為 `slide-01.png`、`slide-02.png`，建立 contact sheet，並用 `scripts/pack_images_to_pptx.py` 或等效方法打包成一頁一張 full-bleed 圖片的 widescreen PPTX。

最後輸出驗證清單：
- 圖片張數是否等於 slide plan 頁數
- 每張圖是否為 16:9 或接近 16:9
- 檔名是否連續
- PPTX 頁數是否正確
- contact sheet 是否能看出一致視覺節奏

已確認的 slide plan 與 SOIL-5：
[貼上已確認內容]
```
